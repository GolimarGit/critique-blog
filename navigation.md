`_posts` folder is for written blog posts
`_site` folder holds the finished website - don't need to modify anything here
`_config.yml` file contains the settings of the site
`Gemfile` file contains the Ruby dependencies
`_layouts` are custom layouts

to start the static site, use
```
jekyll serve
```

if a change to `Gemfile` was made, use
```
bundle exec jekyll serve
```
